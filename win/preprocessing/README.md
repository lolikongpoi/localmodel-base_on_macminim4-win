# QQ 群聊图片缓存预分类

这是一个只在本机运行的 QQ 群聊图片缓存预分类工具。它参考了 `get_sd_netmate_sepictuers` 的分流顺序，并针对日常使用补上了递归扫描、进度、分类清单、重名处理和安全预览。

## 使用方法

1. 首次使用，双击 `setup.bat`。如果习惯中文文件名，`安装环境.bat` 是同一入口。
2. 双击 `start.bat`。`启动预分类.bat` 是同一入口。
3. 选择 QQ 群聊图片缓存目录。旧版 QQ 的常见位置是：`C:\Users\你的用户名\Documents\Tencent Files\你的QQ号\Image\Group2` 或 `Group`。
4. 先保持 `preview`，运行后在输出目录的 `报告` 文件夹检查 CSV 清单。
5. 确认无误后改选 `copy`。只有明确需要改变缓存文件时才使用 `move`。

程序默认输出到本目录的 `分类结果`，不会删除原缓存，也不会覆盖重名文件。界面会显示已用时间、预计完成时间和剩余时间；预计值会在处理若干图片后根据当前平均速度更新。

运行时可点击“暂停”让任务在当前文件完成后暂停，再点击“继续”恢复；点击“停止”会在当前文件完成后结束，并生成已完成部分的报告。停止不会删除已复制或已转换的结果。

当执行方式为 `move` 时，可以勾选“移动时直接丢弃（删除）≤10KB 文件”。确认后，符合条件的源文件会永久删除，而不是进入 `00_小于10KB`；每个删除操作会单独记录在 CSV 中。其他模式不能删除源文件。

结果列表带滚动条，并只保留最近 500 条记录，避免长任务把下方列表占满或拖慢界面。

启动文件内部只使用 ASCII 字符，避免 Windows 批处理对 UTF-8 中文内容的解析问题；它会优先复用上一级“本地识别”已安装的 Python 环境。

目录中的 `tcl_runtime` 是随工具提供的 Tk 图形界面运行时资源，用于兼容本机 Python 的 Tcl 版本差异；请不要删除它。

## 分类规则

分类优先级与原项目一致：

1. 小于等于 10 KB：`00_小于10KB`（原项目删除；本工具保留供复核）。
2. 长宽比超过 4.5：`01_长图`。
3. 任意一边为 1080：`02_含1080边`。
4. 1440 × 2160、2160 × 1440、2560 × 1440、1440 × 2560：`03_2K`。
5. 3840 × 2160、2160 × 3840：`04_4K`。
6. 其余文件按大于 1 MB、100 KB 至 1 MB、10 KB 至 100 KB 分流。

损坏、未完成写入或不能被 Pillow 读取的候选文件会进入 `99_无法读取`，并在 CSV 中保留原因。

没有文件后缀、但能正常解码的 QQ 缓存图片，在 `copy` 或 `move` 时会参照原项目的做法重新编码为 PNG，并以 `.png` 文件名保存。预览模式不会改写任何文件；不能解码的无后缀文件也不会被伪装为 PNG。

## 命令行（可选）

```powershell
.\.venv\Scripts\python.exe .\qq_cache_preclassifier.py "C:\…\Image\Group2" --action preview
.\.venv\Scripts\python.exe .\qq_cache_preclassifier.py "C:\…\Image\Group2" --action copy --output "F:\分类\本地识别\图片预处理\分类结果"
```
