# 图片分类 AIO 控制中心

双击 `启动AIO控制中心.bat` 即可使用。此目录不会修改以下三个原有程序，并兼容原始中文目录和仓库中的英文目录结构：

- `../图片预处理` 或 `../preprocessing`：QQ 缓存图片预分类。
- `../通过mac识别` 或 `../tagging_by_mac`：发送图片到 Mac 并生成 Tag 报告。
- `../移动文件` 或 `../moving`：图片 Tag 安全归档。

## 自动归档

在 AIO 中填写 Mac Tag 报告目录、目标图片库，并填写“已完成数量”或“等待时间”至少一项，点击“开启自动归档”。控制中心会每秒检查一次报告；任一条件满足时，会调用现有安全归档程序的原有流程：完整复制、SHA-256 校验、登记标签数据库，最后才删除已验证原图。

若复制或校验失败，原图不会被删除。自动归档默认关闭，且每次启动都需要手动开启；AIO 只保存目录和阈值，不保存 Mac 的 API key。
